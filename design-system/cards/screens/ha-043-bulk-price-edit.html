Screen — Bulk price edit / weekly view (HA-043)

Manual bulk pricing across a week — the pre-Phase-3 tool before any smart-pricing engine ships, in the same editor frame as ha-038/ha-039/ha-040. A week-strip of seven selectable day columns (Gregorian date + that night's price) replaces the single-date focus of HA-042; tapping columns is a multi-select affordance (weekend columns shown selected in panel B), and a set-price-for-selected Input — the host's own figure, "you set this," never a suggested rate — applies to every selected night at once. A read-only "Your saved weekly pattern" card gives the recurring weekday/weekend split as context (edited by selecting the matching nights below, not a separate screen). The guest-impact line states plainly that a price change only affects new bookings — a guest who already booked keeps the price they paid. Case continuity: host Aqib, Cantt View Residence, Rawalpindi Cantonment, weekday base PKR 12,000 / weekend (Fri–Sat) PKR 15,000 (HA-031's weekend-rate convention). Panels: viewing (light) · selection + bulk input (light) · saved (light) · dark, different week + selection · اردو / RTL.
