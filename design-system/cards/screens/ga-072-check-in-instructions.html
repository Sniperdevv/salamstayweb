Screen — Check-in instructions (GA-072)

Getting in, made foolproof — self check-in as a structured step-by-step wizard: one action per numbered step (gate code → floor → door → lockbox), each code copyable. Because arrival often happens on flaky data or none, the page is a §9-D resilience surface: it caches to the phone and stays fully readable offline — the banner tells the guest so plainly ("Saved to your phone — works without internet"), and if they lose signal it says so calmly without hiding a thing. A host-contact fallback closes the screen for the "can't get in" moment. Panels: saved / online (light) · offline-active state (dark) · اردو / RTL.
