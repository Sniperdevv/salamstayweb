Screen — Finish your verification (GA-115)

Explicit save-and-resume re-entry. Verification is stepped and can be interrupted — by a flaky connection, a wallet hand-off, or simply life — so the draft is held and returned with nothing lost (DESIGN §9-D: optimistic, resumable, offline-queued). The screen picks up exactly where the guest left off, states plainly that progress is saved and syncs when back online, and never blocks or shames. It is entered from the GA-049 status dashboard and from a calm, dismissible home-screen nudge. The same save-and-resume pattern also serves the host listing-wizard resume (HA-063) — noted here as a shared pattern; the host variant is not designed on this card. Panels: resume + offline-queued (light) · home nudge + dashboard entry row (dark) · Urdu / RTL.
