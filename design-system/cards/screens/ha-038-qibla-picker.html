The editor frame replaces the wizard's thin-bar progress + "Host setup · Listing" breadcrumb with a listing context chip — necessary once a host may be managing several live listings from the same section-hub (HA-036). "Re-detect from location" recomputes the bearing from the current map pin without discarding a manual edit until the host chooses it — a deliberate, reversible action, never automatic silent overwrite. Save/Discard and the unsaved-changes bar only appear once the form actually diverges from the saved value (state B); state A and C carry no such bar, only the quiet .laststat confirmation line.
