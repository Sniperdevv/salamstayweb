Screen — Report a person (GA-132)

The user-level report flow — the sibling of the listing report (GA-036), reached from a person's profile ⋯ menu or a message-thread menu (§8.5, §9-E). It is calm and never accusatory: it asks "tell us what happened," it never presumes guilt (§10.6, §10.8). A context chip shows who is being reported (initials avatar, no faces), a plain-language reason picker (harassment · inappropriate messages · suspicious behaviour · safety concern · something else) reveals an optional details note and optional screenshot evidence, and a "what happens next" panel is honest by design: a person reviews every report and the reported person is never told who reported them. The confirmation is factual — routed to the safety team, with no response-time promise (none is offered). Panels: report from a conversation (light) · report from a profile, submit gated (light) · report sent + reason "something else" (dark) · Urdu / RTL.

The context chip is load-bearing: it names exactly who the report is about and where it came from (conversation vs profile) with an initials avatar — never a face on a fictional identity (§8.3 avatar ethics). The reason picker is the same list-row grammar as the listing report (GA-036), in plain, non-accusatory language. Evidence is optional screenshot rows, not a required gate. Submit stays disabled until a reason is chosen, with a plain helper — no dead end, no scolding.
