HW-001 — Host web shell: the create-listing wizard + the host app chrome

The first card in the HW- namespace. It establishes two chromes — the reduced wizard chrome at /host/listings/new/{step} with a sticky action bar carrying nine thin progress bars, and the authenticated app chrome (ha-046 lineage) at /host/listings — plus the column width, the head, the section rhythm, the field anatomy, the disabled-primary treatment, and how a long scrolling body meets a sticky footer. Every /host/* route is noindex, follow. Read the header comment, then HOST-SHELL.md. Panel A is the authoritative semantic page; B–G are variants.
