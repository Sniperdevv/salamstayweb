Screen — Create / edit wishlist (GA-103)

Naming and managing a list, always as a bottom sheet over the screen you came from. Create is one calm field with a helpful placeholder and a single CTA; a private-by-default reassurance sits under it. Edit adds a rename, a horizontal cover picker drawn from the list's own saved photos, and a quiet Delete list — delete is reversible via an Undo snackbar, never a scary "Are you sure?" dialog. Saving drops a plain Changes saved toast. Panels: Create (light) · Edit + cover + delete (dark) · Saved & Deleted-undo toasts (light) · اردو / RTL edit.
