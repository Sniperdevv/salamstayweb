Screen — Saved payment methods (GA-062)

The account-settings wallet at /account/settings/payment — the saved cards, wallets and bank accounts a guest keeps for faster checkout. Each row shows only the masked tail (the tokenised-storage truth stated plainly, ga-053 precedent), one is marked Default, and a per-row menu sets a new default or removes a method — removal resolving to a calm Undo toast, never a scary confirm. "Add a payment method" routes to the GA-052 rail manager (card via HBL · JazzCash · EasyPaisa · Raast). Panels: saved list + row-action menu (light) · saved list + remove Undo toast (dark) · empty state · Urdu / RTL.
