Screen — Notifications center (GA-083)

The in-app history of what's happened, grouped by day (§7.6a: no journey stepper). Rows carry a type glyph — booking update, message, reminder — a title, a one-line snippet, and a timestamp; unread rows read heavier and carry a brand dot (weight + dot, never colour alone). A calm Mark all read sits in the header, every row is a plain tap-through <a> to its context (no swipe gestures to discover), and a quiet row routes to notification preferences (GA-069). The empty state is warm — "You're all caught up." Panels: list with unread (light) · list read + empty state (dark) · اردو / RTL.
