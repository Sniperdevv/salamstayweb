Screen — Hijri calendar preference (GA-082)

How dates read across SalamStay (§7.6a: no journey stepper). A Switch turns on the Hijri date as a quiet second line beside the Gregorian — the default per §10.5, and never a separate "Islamic mode" or a Hijri-primary flip. A calendar-authority Select lets the guest follow the Ruet-e-Hilal Committee or the Khyber Pakhtunkhwa announcement — the regional difference stated factually and respectfully (ARCH §14.1), never adjudicated. The honest moon-sighting note travels with it, a live preview shows a real date in both modes (the GA-071 quiet-secondary treatment), and a note explains Ramadan/Eid-sensitive surfaces follow this setting. Calendar UI is plain text + a neutral calendar glyph — no religious ornament, no green wash (§10.5). Panels: preference on (light) · authority Select open + Hijri-off preview (dark) · اردو / RTL.
