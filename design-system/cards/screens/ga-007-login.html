Behaviour, security & S1 gate compliance · web-variant note
  • Phone / email toggle. A segmented control (inputs §5) swaps the identifier field; phone carries the +92 prefix slot (LTR), email drops it. One primary button, one identifier at a time.
  • Step-up OTP. On a new device or risky sign-in the correct password is followed by a §14 OTP challenge ("Verify it's you") — shared component with GA-005, with resend countdown and a "Can't access this number?" recovery route.
  • Lockout without shame. The attempt cap is a calm outlined role="alert" notice — colour carried by icon + text, never a red fill — with a countdown and two live recovery paths (reset password → GA-008, get help → /help/account-recovery). Copy explicitly reassures ("nothing is wrong with your account"). No dead end.
  • Biometric unlock + fallback ladder. A device-biometric affordance (fingerprint / Face unlock) is offered as convenience on a returning device. Ladder: biometric → device passcode → password → login OTP — biometric is never the only path, and the lockout state still exposes it.
  • No-enumeration security. Wrong-credential errors stay generic ("check your number/email and password") so the screen never reveals whether an account exists — mirrored in GA-008.
  • Real anchors, real controls. Forgot /forgot-password, recovery /help/account-recovery, sign-up /signup, social /auth/google · /auth/apple. Toggle, password eye and biometric are real <button>s with Urdu aria-labels; recovery actions are standalone anchors (no button-in-anchor). [44pt] throughout.
  • On-palette, dignified, bilingual. Every colour is a var() token; monochrome social marks; no ornament; EN/UR label parity; copy is registry-verbatim or plain descriptive — no invented claims.
  • Web variant (/login, SSR→SPA). Same fields in a centred ~440px card on marketing chrome; social side-by-side ≥ md; step-up OTP and lockout render as the same in-card states; keyboard focus-ring on every control; "Remember this device" is an optional checkbox on web that shortens future step-ups.
