GA-022 — states, cultural-UX & a11y coverage

  • States in DOM. Start picked (check-in only, checkout prompt, Next disabled) · range complete (start / in-range / end, 4 nights, Confirm enabled) · Flexible mode (Weekend / A week / A month + month grid) · offline (last saved availability + re-check-on-reconnect — names next step). Unavailable / below-min-stay days are dimmed + struck, never hidden, so guests see why.
  • Hijri as quiet dual info (§10.5). Gregorian primary, Hijri secondary numeral under each day; a labelled Ramadan band + one Eid dot with an accessible label; the honest "approximate / moon sighting" footnote. No crescents, no green wash.
  • Range mechanics (§8.6). Two-tap range, in-range fill uses interactive.subtle, endpoints interactive.primary + text.onBrand, today = border.brand ring; the range half-fill mirrors correctly under RTL.
  • A11y (§11). role="grid" / gridcell; each day's accessible name reads both dates + state, localized to Urdu; Hijri numerals below 18.66px use text.secondary for AA; nav chevrons mirror under RTL; day cells ≥44pt; digits never reversed under RTL.
  • No dead ends. Offline still lets the guest pick and continue; disabled dates explain the minimum-stay rule inline rather than silently blocking.
  • Perf (§12). No imagery; a single month rendered at a time; transform/opacity only; reduced-motion honored.
