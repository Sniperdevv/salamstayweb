Behaviour, security framing & S1 gate compliance · web-variant note
  • Two paths, one grammar. Method choice is a neutral role="radiogroup"; the authenticator path pairs a QR + manual key (§17 variants ledger: "2FA QR/backup codes") with the shared §14 code input; the SMS/WhatsApp path reuses the GA-005 OTP + resend countdown, WhatsApp-first per ARCH.
  • Backup codes are a first-class safety net. Ten one-time codes in a real <table>, with Copy all, a genuine data: Download, plain "store safely" guidance, and a "saved these" checkbox gating Done — the user cannot skip past their own recovery keys.
  • Login challenge with a ladder, not a wall. /login/2fa on a new device asks for the code, then offers backup code → account recovery (GA-011). A lost authenticator is never a dead end (journeys §3.2).
  • Calm security tone (§10.6, §10.8). Copy explains the benefit ("keeps your bookings and messages yours") without fear-marketing, threat counts, or scare words; the confirmation is a quiet success tick, not a celebration; turn-off is visible and reversible with a password re-check.
  • No color-only state. Selected option = border + ring + filled radio; verified digit = border; checkbox = fill + tick glyph; danger row = icon + label. Every state pairs colour with shape or text (DESIGN §11).
  • Real anchors, real controls, [44pt]. Back /account/security, backup codes /…/backup-codes, disable /…/disable, challenge fallbacks /login/2fa/backup-code + /help/account-recovery. Radio options, copy, and checkbox are real <button>/role controls with Urdu accessible names; no href="#", no button-in-anchor.
  • On-palette + QR exception. Every colour is a var() token; the QR alone uses a fixed white card + ink modules because a scannable code must stay dark-on-light in both themes — a functional out-of-theme surface, mirroring the sanctioned social-mark exception in GA-007. No ornament, no invented claims.
  • Web variant (/account/security/2fa-setup · /login/2fa, SPA). Same steps in a centred ~480px card on the settings/auth chrome; the backup-codes table also prints cleanly; the QR sits beside the manual key ≥ md; the login challenge renders identically with a "Remember this device for 30 days" checkbox that shortens future challenges.
