Screen — Min-stay & availability rules (HA-045)

The post-publish editor for stay-length and booking-window rules, in the same editor frame as ha-038/ha-039/ha-040: app bar + listing context chip + save/discard + unsaved-changes bar — no wizard bars. Min/max-stay steppers reuse HA-032's grammar byte-for-byte, plus a new weekend-specific minimum-stay toggle (ha-031's switch-row pattern) for hosts who want longer Friday/Saturday-night bookings. Advance notice and preparation time reuse HA-032's Select shell and starting values — but unlike HA-040's backup-power link (which stays owned elsewhere, HA-074), this editor owns the live values: the listing wizard (HA-032) only ran once at creation, and everything here is what a host actually manages afterward — the screen states this plainly rather than pointing back to a wizard step that no longer applies. A new booking-window Select ("how far ahead guests can book") and a rule-impact preview give a concrete, arithmetic example of what the current rules mean for a real guest — never a market stat. Case continuity: host Aqib, Cantt View Residence, Rawalpindi Cantonment, carrying forward HA-032's exact 2-night min / 21-night max example.
