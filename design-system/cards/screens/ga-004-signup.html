Behaviour, cultural law & S1 gate compliance · web-variant note
  • CNIC is just-in-time, never an upfront wall. Sign-up asks only for a phone number; the CNIC line is a calm info banner ("you'll verify before you book — not now") carrying the SEO-RULES §5 claim CNIC-verified guests and hosts via NADRA Verisys verbatim. The full capture lives downstream at GA-041.
  • The foreigner branch is a quiet link. "Not from Pakistan? Continue with a passport" routes to /signup/passport — never a loud toggle, never presuming everyone holds a CNIC.
  • Social = entry affordances (GA-006). Google / Apple are secondary buttons that sit above the number field. Rendered monochrome (text.primary) to stay token-pure — see judgment note below.
  • Real anchors only. Terms /legal/terms, Privacy /legal/privacy, verification /legal/verification, passport /signup/passport, login /login, social /auth/google · /auth/apple. No href="#", no clickable divs; the CTA and back are real controls.
  • No dead ends. Empty number → Continue is a disabled affordance; invalid number → a role="alert" field error stating exactly what to fix; submit → width-locked spinner then forward to GA-005.
  • +92 prefix Input variant. Fixed non-editable text.secondary "+92" prefix slot with a hairline divider; national number in the editable area, tabular, LTR under both directions (inputs doc §2 / §17).
  • On-palette, no ornament. Every colour resolves through a var() token; one calm brand button; no religious ornamentation, no gold, no green-washed fill. Copy is registry-verbatim or plain descriptive — no invented stats, ratings, or testimonials.
  • Web variant (/signup, SSR→SPA). Same fields in a centred single-column card (max ~440px) on the marketing chrome; social buttons side-by-side ≥ md; the phone frame becomes a page section; keyboard focus-ring on every control; Terms/Privacy as inline anchors. Identical copy, identical CNIC just-in-time framing.
