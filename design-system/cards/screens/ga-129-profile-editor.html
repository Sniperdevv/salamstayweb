Screen — Profile editor (GA-129)

The editor for the guest profile (DESIGN §9-J). A single scrollable field list where every about-prompt carries its own per-item visibility Switch ("Shown on profile" / "Only you"), privacy-first: intro shows the expanded Textarea edit state; decade-born ships visibility off by default (value locked once set, only the decade ever shown). A photo slot frames the photo as optional for guests — "Add a photo" and "you don't need a photo" carry equal weight (§9-J/§10.7), routing to the guided capture GA-130. Below, a travel-stamp manager toggles each stamp on/off. Panels: full editor (light) · photo set + save toast · dark (decade off) · اردو / RTL.

The stamp manager toggles each stay: the third stamp is Only you, so it is dimmed with an eye-off marker here and simply absent in the public view (§8.3) — which is exactly why "3 trips" can show two public stamps.
