Screen — Cultural-attributes editor (HA-037)

The standalone editor for a live listing's Shariah-respectful attributes, reached from the Edit-listing hub (HA-036). It renders the same 9 toggles and badge preview as the wizard step HA-023 — identical icons, labels and guest-facing sentences — but in an editor frame: no wizard progress bars, and the wizard's "Host setup · Listing" breadcrumb is replaced by an editor app-bar titled "Cultural attributes" with a listing-context chip (property name + a live status pill, linking back to the hub). A guest-impact note states plainly that changes publish immediately — there is no review queue for these facts, unlike document verification. Editing produces a real unsaved-changes bar (Discard / Save) and a save toast on confirm. Case: host Aqib, Cantt View Residence, Rawalpindi Cantonment (live since HA-034).
