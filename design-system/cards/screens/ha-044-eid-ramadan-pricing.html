Screen — Eid / Ramadan pricing setup (HA-044)

Practical seasonal pricing for the three Islamic-calendar periods a Pakistani host actually plans around — Ramadan, Eid al-Fitr, Eid al-Adha — treated exactly like any other seasonal-pricing tool (DESIGN §10.5): demand around these periods is real, but the screen carries **no ornament**, only plain period rows in the same editor frame as ha-038/ha-039/ha-040. Each period shows Gregorian primary + Hijri quiet-secondary, reusing GA-022/HA-032's dual-date convention and their exact honesty footnote verbatim. A per-period toggle (ha-031's switch grammar) reveals a nightly-rate Input — the host's own figure, "you set your price" (HA-002/HA-031 precedent) — never a suggested surge percentage or an invented demand statistic (NEVER #3). The **no-pressure default** banner states plainly that the base rate applies to every period until the host says otherwise; an optional min-stay stepper lets a host require a longer booking over Eid travel dates. Case continuity: host Aqib, Cantt View Residence, Rawalpindi Cantonment, base rate PKR 12,000/night (HA-031).
