Step 1 of 9 at /host/listings/new/property-type. Fixes the shape shared by four of the nine steps: a 2-up grid of icon cards for a set of peers, and full-width option rows for a small set of consequential choices. One anatomy, two containers. Chrome, column, type ladder, bars and token block are hw-001's, unchanged — read HOST-SHELL.md, then this card's header comment for what is new. Panel A is the authoritative semantic page; B–G are variants.

B · The option card, all four renderings side by side
A screenshot only ever catches one state, so this panel forces all four. .is-hover and .is-focus reproduce the :hover and :focus-visible declarations exactly — the same device as the .nar panel scope, and like it, card-only: neither class reaches product markup. Read the four in order: the resting border is border.default; hover deepens it to border.strong and nothing else moves; keyboard focus is the shared --focus-ring, offset from the canvas so it survives a dark theme; selection is a 2px inset ink ring with the mark filled and a white check, and the fill never changes — so no text shifts by a single pixel when the host picks one. Hover is gated behind (hover:hover) and (pointer:fine) so a tap never leaves a card looking hovered.

E · Dark — every role re-resolves; the ink ring inverts to near-white
Dark is a theme rendering, not a second design: no second h1, no landmarks. Watch the selection: interactive.selected flips from near-black to near-white and its check flips with it, so "selected" stays the highest-contrast thing on the card in both themes without ever reaching for green.
