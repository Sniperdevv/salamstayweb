# Monitors — schema, emptiness rule, regeneration trigger

> **S0 status: all eight monitor files are empty-by-design (header row only, zero data rows).**
> A monitor file is a *defect ledger*: a row in it is a failure. These files are generated by the
> GATE 66/67 SEO test suite (`specs/testing-and-publishing.md`) running against `next build` + a crawl
> of the preview/staging deployment (production-like rendered HTML) — never against source files alone.
> **They are empty now because there is no rendered site to scan yet, not because the site is clean.**
> Their meaning turns on at S2/S4/S5.

**Interpretation rule:** a file being empty is a *pass* only once its generator has actually run against
rendered output. At S0 (no code) "empty" means "not yet measured" — do **not** read S0 emptiness as a
green light. The manifest scores these areas on **spec quality only** and caps enforcement at ~0.

## Per-file schema + regeneration trigger

- **`fact-conflicts.csv`** — `Entity, Attribute, Value one, Value two, URLs, Files, Intended source of truth, Severity, Required correction`.
  One row per cross-surface fact contradiction (e.g. two different listing totals, price ≠ schema).
  **Trigger:** the FACT reconciler (source-of-truth `R4`) on every merge (S2) + pre-deploy (S4). Regenerated each build.
- **`locale-errors.csv`** — `URL, Language, Incorrect currency, Incorrect spelling / transliteration, Incorrect amenity or property fact, Incorrect landmark / area reference, Incorrect city / province reference, Incorrect legal or commercial statement, Source component, Required fix`.
  **Trigger:** the transliteration scanner + PKR-format + language-contamination checks (`locale-architecture.md` L2 hooks 5/6, tests #14/#15) on S2/S4.
- **`canonical-hreflang.csv`** — `URL, Canonical, Canonical status, Self-canonical result, Hreflang values, Reciprocity result, Target status, Target canonical status, Error description`.
  **Trigger:** canonical + hreflang reciprocity crawl (tests #6–#12; `redirects-canonicals.md` / `locale-architecture.md` hooks) pre-deploy (S4).
- **`duplicate-clusters.csv`** — `Cluster ID, URLs, Page types, Exact similarity, Structural similarity, Sentence overlap, Semantic similarity, Shared intent, Required action, Preferred URL`.
  **Trigger:** the 6-method similarity job (`similarity-and-content-quality.md §3`, tests #31/#32) S2/S4 + continuous S5.
- **`cannibalisation.csv`** — `Query or intent, Competing URLs, Impressions, Clicks, Positions, Intended owner, Current likely owner, Evidence of harm, Required action`.
  **Trigger:** pre-launch = registry collision pre-check (`page-intent-map.csv`, one-owner); post-launch (S5) = Search Console query×page join (G34/G35).
- **`structured-data.csv`** — `URL, Schema type, Validation status, Visible-content match, Price match, Currency match, Rating match, Canonical match, Errors, Warnings, Required fix`.
  **Trigger:** JSON-LD validator + schema-vs-visible differ (tests #21/#23/#24/#39) S2/S4.
- **`content-quality.csv`** — `URL, Unique text percentage, Boilerplate percentage, Word count, Unique factual statements, Unsupported claims, Placeholder count, Source count, Last verified date, Location-specific value score, Scaled-content risk, Required action`.
  **Trigger:** thin/scaled checks + placeholder scan + claims scanner (tests #16/#31/#32; `similarity §4`, G53) S2/S3/S4.
- **`rendering.csv`** — `URL, Initial HTML word count, Rendered HTML word count, Missing initial content, Client-only headings, Client-only links, Duplicate rendered blocks, Hydration errors, JavaScript failures, Required action`.
  **Trigger:** initial-HTML-vs-rendered diff (tests #40/#41; `rendering-and-routes.md` L2 hooks 1/3) S4.
